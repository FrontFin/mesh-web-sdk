## Development

This repo uses **pnpm** (not yarn) and requires **Node >= 22.13** — pnpm 11 will
refuse to run on older versions.

```bash
corepack enable   # picks up the pinned pnpm from "packageManager"
pnpm install
```

Dependency installs enforce a 24h cooldown on freshly published versions
(`minimumReleaseAge` in [pnpm-workspace.yaml](pnpm-workspace.yaml), see
[SR-16](https://linear.app/meshconnect/issue/PRG-324)). If you bump a dependency
to a version published today, the install will fail by design — wait, or pick an
older version.

If you install with `--ignore-scripts` (as CI does), also run:

```bash
pnpm --filter @meshconnect/web-link-sdk run updateVersion
```

That generates `packages/link/src/utils/version.ts`, which is gitignored. Without
it `pnpm typecheck` fails on a missing module — it is normally created by the root
`postinstall`, which `--ignore-scripts` suppresses.
